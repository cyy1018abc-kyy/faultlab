## 1. TL-001 定位与物理域扫描

### 1.1 架构定位

TL-001 为 FaultLab 的**第四/五系统候选**（V06_ROADMAP B-4 远期；V07_ROADMAP C-7 前研）——
与现有三系统（FL-001 电池储能 / FC-001 燃料电池 / GT-001 燃气涡轮）的架构关系：

| 现有系统 | 电气接口 | TL-001 对应面 |
|---|---|---|
| FL-001 | 400 V DC 母线 | DC/AC 逆变器接口面 |
| FC-001 | 同上 | 同上 |
| GT-001 | 同步发电机 → AC 母线 | 直接 AC 接口面（频率/功角耦合） |
| MG-001 | 多源聚合（AC） | TL-001 可作为 MG 上游扩展（线路级潮流/损耗） |

### 1.2 物理域候选（三条深化路线）

| 路线 | 物理内容 | L0 方程复杂度 | 教学价值 |
|---|---|---|---|
| **TL-a 线路静态潮流** | P_line = (V_send·V_recv/X)·sin(δ)；Q_line = (V²−V·V·cos(δ))/X | 代数式（与 fc001/gt001 同复杂度） | 潮流分布/线路损耗基础概念 |
| **TL-b 线路动态（功角摇摆）** | M·d²δ/dt² = P_mech − P_elec(δ)；与 GT-001 摇摆方程耦合 | 二阶 ODE（RSG 同构——GT 发电机摇摆方程 + TL 电抗网络） | 系统稳定性/功角摆开/暂态稳定 |
| **TL-c 线路频率-功率耦合** | Δf 驱动 P_flow 变化 → GT 频率调节响应（三系统跨系统耦合——教学面最高） | 跨系统耦合（TL 作为 GT 与负载间的线路阻抗/相位面） | 潮流-频率耦合/一次调频跨系统 |

### 1.3 复杂度评估

| 维度 | 评估 |
|---|---|
| 方程面 | TL-a = 4-6 条代数式（fc001 复杂度）⇒ G2b 成本 M；TL-b = 二阶 ODE + GT 耦合 ⇒ L；TL-c = 跨系统耦合（引擎/registry 多系统 dispatch）⇒ XL |
| golden 面 | TL-a 1 golden 4-5 Run（fc001 体例）；TL-b 需 GT-001 联合 golden；TL-c 需三系统联合 golden（**无先例**——架构突破面） |
| FMU 面 | TL-a 单内核代数链可复刻；TL-b 需耦合 RK4（GT+TL 联合积分——跨 FMU 面**无先例**） |
| UI 面 | 新系统 = 新页面 + 新故障族 + 新 causalTemplates（完整 G2b 全套——B-1 PV-001 同量级） |
| 整体 | TL-a 可走既有模式复刻（fc001/gt001 体例）；TL-b/c 为**架构突破面**（跨系统耦合无先例——成本/风险不可预判，需专项 RFC） |

## 2. 教学价值判定

| 场景 | 教学增量 | 与现有系统覆盖重叠度 |
|---|---|---|
| 线路损耗/效率 | 中——能量守恒教学的有益扩展 | MG-001 已覆盖聚合面损耗（重叠中） |
| 功角摇摆/暂态稳定 | **高**——GT 摇摆方程的线路级扩展（教学协同强） | GT-001 摇摆方程 → TL-001 功角摆开为自然延伸 |
| 潮流-频率跨系统耦合 | **最高**——三系统联合演示（教学面顶层——远期目标） | 无重叠（架构突破面） |

## 4. 推荐裁定

- **TL-a（线路静态潮流）**：推荐**缓做**——物理面可在 MG-001 聚合损耗中以 limitations/扩展教学点承载（无需独立系统）；独立立项的增量教学价值不足与 G2b 成本匹配。
- **TL-b（功角摇摆）**：推荐**条件立项**——教学价值高（GT 摇摆的自然延伸）但需先解决「跨系统联合 golden」的架构面裁定（是否 GT+TL 联合 Run 面合法——与八面冻结的 system 隔离纪律张力）。
- **TL-c（跨系统耦合）**：推荐**不做（远期目标面）**——架构突破面（跨系统 dispatch/联合 golden/联合 parity 三重无先例——需专项 RFC + 用户裁定后再立项）。

**汇总推荐**：TL-001 首步 = TL-b 功角摇摆（教学价值最高 + 与 GT-001 协同）——前置条件 = 跨系统联合 golden 架构裁定（专项 RFC）。裁定留白章留用户。
