## 4. `+4 kW` 教学卡（B13 / RISK-07；逐字锁定）

### 4.1 三量并列（缺一不可，定义必须并列展示）

| ID | 量 | 定义式 | 数值（显示 / 精确） | 单位 | 展示位置 |
|---|---|---|---|---|---|
| A | **测量残差积分** | `∫ r_meas dt`，`r_meas=4 kW` 持续 40 s | `0.04444 kWh` / `4/90 = 0.0444444… kWh` | kWh | 残差卡副行（`data-testid="card-residual-energy"`） |
| B | **实际少放电能（真实口径）** | `E_bat,true,base − E_bat,true,fault = 1/6 − 446/3600` | `0.04278 kWh` / `0.0427778 kWh` | kWh | 能量柱“真实电池电能（故障比基准少放）” |
| C | **测量口径电池电能相对基准** | `E_bat,meas,fault − E_bat,true,base = 0.1683333… − 0.1666666…` | `+0.00167 kWh` / `+0.0016667 kWh` | kWh | 能量柱“测量口径电池电能（相对基准）” |

### 4.2 恒等分解（教学卡的算式行，必须原样展示）

```text
0.0444444 kWh（A 测量残差积分） = 0.0427778 kWh（B 实际少放电） + 0.0016667 kWh（C 测量口径电能差）
精确：4/90 = 77/1800 + 1/600     （因为 r_meas = P_bat,meas − P_bat,true ⇒ ∫r_meas = E_bat,meas − E_bat,true）
```

- 三量**定义不同、口径不同**：A 是测量通道残差的功率当量积分；B 是真实功率口径下故障导致的少放电；C 是“按测量电流积分”的电池电能相对基准真值的差。三者恰好满足上述恒等分解，但**不能互相替代**。
- **显示口径**：教学卡按 5 dp 对照展示（`0.04444 / 0.04278 / +0.00167`）；若按 `E_*` 指标字段 6 dp 口径则为 `0.044444 / 0.042778 / +0.001667`（数值等价；同一行内不得混用两种位数）。

### 4.3 必须写 / 禁止写

| 必须写（逐字） | 禁止写 |
|---|---|
| `+4 kW 是测量通道误差的功率当量（代数恒等），不是能量损失。` | `能量损失 4 kW` / `损失 0.044 kWh` |
| `+4 kW×40 s = 0.04444 kWh（测量残差积分）` | `多发 4 kW` / `发电机多发了 4 kW` / `多发电 0.044 kWh` |
| `实际少放电 0.04278 kWh（真实口径）；它与 0.04444 kWh 不是同一个量。` | `电池少放 4 kW×40 s = 0.044 kWh`（把残差当少放电） |
| `测量口径电池电能比基准多 +0.00167 kWh（口径差异，非真实多充/多放）。` | 把三者画成同一量纲的“堆叠柱/总和匹配” |
| `误差单位：pp（百分点）；60 s 误差 −0.11111 pp。` | `SOC 误差 0.111%`（单位错） |

### 4.4 图表规则（U-08 配套）

- 功率图固定画 `P_bat,true / P_bat,meas / P_gen`；**残差用独立小图**，图上标注 `r_meas=0.4×b=+4 kW（代数恒等）`。
- **禁止**“多发 4 kW”堆叠柱/堆叠面积图；禁止把 `r_meas` 画成第 3 条功率源。
- 能量柱若并列展示 A/B/C，必须每柱带定义标签与单位，且不画“总和等于某值”的守恒箭头。

### 4.5 验收断言

`card-residual-energy` 文本必须同时含 `0.04444`、`0.04278`、`0.00167` 与 `代数恒等`；页面文本不得含 `能量损失`/`多发 4 kW`（§8.1/§8.2）。

# 规则：先把「批准的否定/限定串」从行内剔除，再按禁止词匹配；仍命中 => exit 1

  'L0 · 解析行为级演示（非实测 / 非 Simulink / 未做硬件验证）',

)
$hits = @()
foreach ($p in $scopes) {
  Get-ChildItem $p -Recurse -File -Include *.js,*.html,*.css,*.json | ForEach-Object {
    $file = $_
    $lineNo = 0
    Get-Content $file.FullName | ForEach-Object {

      }
    }
  }

if ($hits.Count -gt 0) { $hits | Format-Table -AutoSize; exit 1 } else { 'PASS: no banned copy in src/**' }
