## 发现清单

### BLOCKER（批准即冻结错误/不可实施物理）

**R-A-01 §1 EQ-TL-3/4/5（:31-33）+ §3 列名（:64）+ §4 Q2（:71）——δ/ω 单位制三义未决 + TL 参数表整体缺失（无值/无单位/无基值/V_gen 映射弃用/初值缺失）——冻结表不可唯一实施。**

- **(1) ω 单位制三义**：EQ-TL-3「dδ/dt = ω_s·(ω − ω₀)」与「ω_s = 2π·f₀ = 314.159」（RFC §3 TL-EQ-1 :94 同）组合仅当 (ω−ω₀) 为**无量纲 p.u.** 时量纲闭合（教科书形 dδ/dt = ω_s·Δω_pu，Kundur/Anderson 口径）；若 ω 为 **Hz**（GT 侧口径），需 ω_s = 2π ≈ 6.2832 rad/Hz——与 314.159 差 **50 倍**；若 ω 为 **rad/s**（golden 列名 **ω_rad_s**（:64）预判），需 ω_s ≡ 1（dδ/dt = ω − ω₀_rad_s）——与 314.159 差 **314 倍**。ω₀ 数值全文未定义（50？314.159？1.0？）。三种自洽制并存而草案混装（p.u. 制的 ω_s + rad/s 制的列名）——两名称合格的实施者将产出定性不同物理。
- **(2) M 量纲**：RFC 参数候选「M（H）3–8 s」（:105）为 H 惯量常数口径（(2H/ω_s)·d²δ/dt² = P_pu 教科书形），与 EQ-TL-4 字面 M·dω/dt = P(kW) 不兼容——kW 口径需 M[kW·s/Hz]（ω Hz 制，= 2H·S_base/f₀）、M[kW·s²/rad]（rad/s 制，= 2H·S_base/ω_s）或 M[kW·s]（p.u. 制，= 2H·S_base），换算依赖**基值功率 S_base——全文未声明**。
- **(3) D 量纲**：RFC「0.02–0.05 p.u./p.u.」（:106）与 EQ-TL-4 的 D·(ω−ω₀)（P 为 kW）不兼容——需 D[kW/Hz] = D_pu·S_base/f₀（复算：D_pu=0.02、S_base=25 kW、f₀=50 → 0.01 kW/Hz，对照 K_bat=24 kW/Hz）或对应制换算。
- **(4) X_line/V 口径与功率基值**：RFC「X_line 0.5–1.0 p.u.」（:104）+ EQ-TL-5「P_elec = (V_gen·V_inf/X_line)·sin(δ)」+ golden 列 **P_elec_kW**——V²/X 出 kW 需 X 为 Ω，或全 p.u. + 基值声明；**S_base/V_base/Z_base 均未声明，p.u. 参数与 kW 功率流直接混写**。数值自查（评审独立复算）：若按 S_base = 25 kW（设计点 P_gen）/V_base = 400 V → Z_base = 6.4 Ω → X = 0.5 p.u. = 3.2 Ω → P_max = 400·400/3.2 = 50 kW → δ_eq = arcsin(25/50) = **30°**（教学可见 ✓）；**X = 1.0 p.u. 角点 → P_max = 25 kW = P_export → δ_eq = 90° 恰在静态稳定边界**（零裕度——joint_load_step 下 P_elec 需求 35 kW > P_max，无平衡点、立即失步）——角点行为须显式登记。参数可救（基值声明即可），但现文未声明。
- **(5) V_gen 未定义（RFC TL-EQ-5 静默弃用）**：RFC §3 TL-EQ-5「V_gen ≈ f_GT/f₀·V_rated」(:98) 在草案 EQ 表中**无对应行**——V_gen 是常数（V_rated = 400 V）还是 f 映射未声明；弃用该映射还改变耦合物理（GT 频率不再影响 P_elec 幅值，仅经 δ 动态间接耦合）——弃用须显式裁定，不静默。
- **(6) δ/ω 初值缺失**：§2 joint_healthy 声称「δ 稳态、ω 稳态——功角平衡」（:55）——稳态要求 δ(0) = δ_eq（替换形下 δ_eq = arcsin((P_load−P_bat)·X_line/(V_gen·V_inf))，复算 25 kW/50 kW → 30°）、ω(0) = ω₀——初值表全文缺失，IC 不设则 healthy 非定点、该教学声明不成立。
- **建议**：批准前补一节「TL 参数与单位制表」承载：单位制选定（**推荐**：δ 电弧度 + f 沿 GT Hz 口径——与 R-A-02 单转子形合并后 dδ/dt = 2π·(f−f₀)，ω_s 因子消去、ω_rad_s 列改代数导出列 ω = 2π·f；若坚持双态形则须从 Hz/rad-s/p.u. 三制显式选定并全文名对齐含列名）+ S_base/V_base/Z_base + X/M/D 换算值 + 角点登记（X=1.0 → δ_eq=90° 边界）+ V_gen 定案 + IC 表（δ(0)=δ_eq、ω(0)=ω₀、f(0)=50、T3(0)=1173）。

**R-A-02 §1 联合耦合面（:35-41）+「关键区别」段（:43-45）+ §4 Q1（:70）——耦合面功率平衡物理不自洽：同一发电机转子双建模 + P_elec 符号相反对消（幻影耦合）——SMIB 核心物理缺失。**

- **双转子**：EQ-TL-1 的 f（GT-001 转子，K_J = 5 kW·s/Hz 转子惯量，GTL1 §2.1 :145）与 EQ-TL-4 的 ω（RFC TL-EQ-2 :95 明注「**发电机转子动力学**（M = 惯量常数）」）是**同一物理转子**——联合态 y = [f,T3,δ,ω] 把一个转子建成两个独立 ODE（K_J 与 M 双惯量、无轴刚度耦合、无 f≡ω 运动学约束，可无限背离）。复算量级：按 R-A-01 推荐基值换算 M ≈ 2H·S_base/f₀ = 2·5·25/50 = **5 kW·s/Hz，与 K_J 同值量级**——双惯量冗余非小量。
- **幻影耦合（可从草案原文逐字求和验证）**：f 式加速功率 P_f = **P_elec** + P_bat − P_load（:40「GT 的 P_rotor = P_elec + P_bat − P_load」）；ω 式加速功率 P_ω = P_gen_GT − **P_elec** − D·Δω（:39「TL 的 P_mech = P_gen_GT」代入 :32 EQ-TL-4）。**求和：P_f + P_ω = P_gen_GT + P_bat − P_load − D·Δω——与 P_elec 无关**。即线路交换功率在联合系统总加速平衡中**逐项抵消**：无穷母线既不向孤岛注入也不吸收净功率（多送电不减速、少送电不加速）——SMIB 的「出力↑→转子减速→δ 摆→同步力矩回拉」机制不存在；f 式中出口功率以「发电」符号进入（+P_elec 在 P_rotor）亦与物理惯例相逆。教学声明「TL 耦合改变了 GT 动态」（:44-45）只会经「单转子失衡拆分到双惯量」的数值伪影实现，而非真实并网耦合。
- **稳态面公平记录**：联合固定点存在（P_rotor=0 → P_elec=25 kW；Δω=0 → P_gen_GT=P_elec=25 kW = 设计点）——§2 joint_healthy 的稳态声明可成立；缺陷在暂态耦合机制，不在定点存在性。
- **Q1 为单选项决策点**：§4 Q1 仅列「(a) P_elec 替代 P_gen（真耦合）」——无备选案，不构成裁定面（与 §4「全候选」自述 :3 矛盾）。
- **修正方向（最小编辑、保留全部已批架构与教学面）——单转子形**：EQ-TL-1 保留 EQ-GTL1-7 恒等结构、增一项出口消耗：**P_rotor = P_gen + P_bat − P_load − P_elec(δ)**（P_gen = 机械输入沿 GTL1 口径；−P_elec = 线路出力）；δ 降为受驱角度态 **dδ/dt = ω_s·(f − f₀)/f₀ = 2π·(f − f₀)**（δ 电弧度、f Hz——ω 态删除或 ω_rad_s = 2π·f 代数导出列）；EQ-TL-4 溶解为 P_elec 代数链（D 阻尼可选并入 P_rotor 为 −D·(f−f₀) 项）。此形下：EQ-GTL1-7 恒等结构保留（涟漪 = 单一新增项）、SMIB 功角摇摆真实出现、联合轨 ≠ 独立轨声明保持、**joint_gt_standalone 退化条件变为 P_elec ≡ 0（线路开断）——比替代形 P_elec ≡ P_gen 更物理**（见 R-A-03）。权限依据：CHG-20261120-01 ①（DECISIONS.md :1937）明载 **R-CS-02 = TL-b 物理域方程候选 TL-EQ-1..5「G2b 草案轮定案细则」**——本草案轮即方程定案轮，修订方程集在授权范围内，不与已批 R-CS-01 架构（方案 A 松耦合/联合 RK4 单内核/命名）冲突。
