## 1. 发布定位

v0.4.0 完成了 GT-001/FC-001 正式化标注 + 后端对照框架 + 评测轨框架。v0.5.0 的核心增量是：
**FC-001 approved_fc 首次进入发布物**（v0.4.0 只做了分类变更，FC 的 Run 尚未在正式场景中展示）、
**L1 数值模型探路**（Q-4 守卫下的可行性评估）、**评测轨场次扩容**（多 Agent / 多场次并行）、
**GT-001 UI 正式化收尾**（本批已完成的 level/summary 升格归入）。
