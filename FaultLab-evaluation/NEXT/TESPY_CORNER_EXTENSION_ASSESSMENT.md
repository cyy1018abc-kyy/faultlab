## 0. 定位与边界

- **「TESPy 角点扩展」是什么**：GT-L1 稳态自洽**旁证轨**（非门禁阻塞项）的剩余面补全——
  tespy-independent-case.md §6.2 明文登记：本结论只覆盖设计点（u=25），GTL1 §5 声明的两个
  稳态角点（sensor +0.3 的 u=19.65、u=40 钳位）与真 TESPy（变比热，口径 (b)）对照**未执行**。
- **不是什么**：不是模型验证（三标签不合并——`model_validation` 维持 `not_performed`）、
  不是设备性能声明（I-5）、不把 TESPy 输出当真值（GTL1 §5 原文）、不是新仿真轨（纯稳态
  代数链复算，EQ-GTL1-1…8 同式）、不是 CI/门禁项（旁证轨非门禁）。
- **与 L1 边界关系**：零边界扩张——复算对象是既有 L1 代数链的稳态闭合性，不新增方程、
  不新增状态变量、不触碰 golden；ALINE §1.2「新增物理 → 完整 G2b」不触发。

  （`Source(ISO 大气) → Compressor(π_c=8, ε_c=0.82) → CombustionChamber(LHV=50000, η_b=0.99,

## 2. 候选扩展角点清单

> 每项五元组：角点定义 / 物理动机 / 与 L1 边界关系 / 治理成本 / 推荐时点。
> 工况参数的具体取值（f/T3/u/P_load 的角点稳态值）不在本稿预填——随实现轮从
> `gt001_l1_oracle.py` 现有 `chain_algebra(f, T3, u, P_load)` 接口与 golden 现值直取。

### C1 u=19.65 —— sensor +0.3 指令域稳态角点

- **角点定义**：sensor_bias +0.3（传感器偏置故障族）下调速器积分收敛的燃料指令渐近稳态
  u_ss = 19.65 kW_eq（GTL1 §3.3 :289「同稳态、异指令」行——对应 L0b P_gen_cmd = 17.80 kW，
  指令域不同不可直比）。对该稳态点做代数链复算，输出 T2/p2/T4/P_comp/P_turb/η_cycle，
  与 oracle 同参稳态解比对（GL-1 同构判据）。
- **物理动机**：这是「设计点之外第一个非平凡稳态」——传感器偏置下闭环把真实量拉到偏置
  表观值、指令域与功率域分歧的跨深度教学锚点（该数值已进 teaching 跨深度路径文案与
  golden 对比表）；旁证复算确认 L1 代数链在偏置稳态点同样闭合，补全旁证覆盖面。
- **与 L1 边界关系**：零边界扩张（EQ-GTL1-1…8 同式稳态复算，不触动态轨/golden）。
- **治理成本**：S——单点 stdlib 复算 + 证据文档增补；临时脚本纪律（SHA-256 登记、`-I`
  运行、用后即删）照旧。
- **推荐时点**：v1.1.x 候选（与 C2 同批，见 §6）。

### C2 u=40 钳位 —— 指令域饱和角点

- **角点定义**：燃料指令域钳位上限 u_cap = 40 kW_eq（magnitude 100%）下的稳态——对应
  P_gen 物理包络上端 ~44.98 kW（load_step +20 角点近完全恢复值，§3.3 :297）与 T3 注册域
  上端 1524.9 K 邻域（§3.3 :309「上端 = u=40 钳位/load +20 角点」）。同 C1 方式复算比对。
- **物理动机**：饱和工况是 L0b/L1 能力包络差异的承载点（L0b 钳电功率 [0,40] vs L1 钳燃料
  指令、P_gen 包络 [−8.3, +44.98]——Q5 已定案 v1.0：指令域口径保留）；旁证确认钳位稳态
  下热力链闭合，与域扫描（§3.5）稳态值互为独立确认（账面重叠见 R2）。
- **与 L1 边界关系**：零边界扩张；数值与 §3.5 域扫描现值同源引用，不重跑动态轨。
- **治理成本**：S——同 C1 同批执行（同一复算脚本两个工况点）。
- **推荐时点**：v1.1.x 候选。

### C3 真 TESPy 口径 (b) 对照（设计点 + 两角点）

- **角点定义**：评审人/用户**自备仓库外环境**安装真 TESPy（默认变比热物性），按 GTL1 §5
  声明式链对设计点 u=25 与 C1/C2 两角点输出六量，与 oracle 稳态解比对——差异作为
  「变比热豁免（§2.2）的已解释偏差」登记，只比趋势与量级。
- **物理动机**：口径 (a)（常量同源）只能旁证「方程实现自洽」；口径 (b) 才引入独立物性面
  （变比热），是唯一能实测「定比热豁免偏差幅度」的对照面——旁证轨的完整形态。
- **与 L1 边界关系**：零边界扩张——仓库内只落 Markdown 证据（数值表 + TESPy 版本号 +
  LICENSE 核实记录 + 偏差解释，GTL1 §5「产出与隔离」原文）；零代码零依赖入库。
- **治理成本**：M——**硬前置 = TESPy LICENSE 原文直读核实**（GTL1 §5 纪律 4 +
  REFERENCES R-TESPy「待核对」回填），当前执行环境无网络不可达；执行在评审人/用户自备
  环境，仓库侧成本只有证据登记。
- **推荐时点**：v1.2 候选（依赖网络/环境条件；不阻塞任何门禁）。

### C4 u=0 / u_min 域外角点 —— **不推荐**（列此存档，见 §4 不做清单）

- **角点定义**：u=0（负净功 −8.30 kW 外推伪影）与注册域下端 u_min=6.98（sensor +1.0 角点，
  不可达）的复算。
- **否决理由**：u=0 是 §3.3 :312 已登记的模型外推伪影（物理对应停机/盘车，未建模，注册域
  外不可达）——旁证复算一个物理上不存在的工况，收益为负且可能被误读为对伪影的背书；
  「仍登记 limitations + 未来开放燃料配置须先立钳位」的原处置已足够。

## 3. 推荐结论

**维持旁证轨定位与产品面外身份不变；推荐 C1+C2 以 stdlib 定比热口径 (a) 复算补全两个
稳态角点作为 v1.1.x 候选小项（S 规模，GL-1 同构判据，证据增补现旁证文件），C3 真 TESPy
口径 (b) 对照以 LICENSE 核实回填为硬前置列 v1.2 候选（评审人/用户自备环境），C4 不做。**
三标签纪律、GPL 隔离、I-1 零依赖、golden 零触碰在全部候选中维持。
