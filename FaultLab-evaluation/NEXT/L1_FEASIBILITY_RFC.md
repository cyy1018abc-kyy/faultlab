# L1_FEASIBILITY_RFC — L1 数值模型可行性评估（Q-4 三守卫适用）

> **任务**：V0.5.0 规划 L-1（Lead 建议稿 2026-10-31）。
> **Q-4 三守卫适用**：(1) 准入门绑定 FL-001 方程集（本 RFC 评估新方程 → **自始无效须走 G2b**）；
> (2) 许可证核实为前置；(3) 验收路径禁入直至各自 RFC + G2b 通过。
> **结论**：本 RFC 评估的是 L1 的**可行性与成本**，**不构成实现授权**。

---

## 1. L1 是什么

L0（现有）= 解析/行为级：方程可手解、输出确定、golden 可 oracle 复算。
L1 = 数值仿真级：方程不可手解（ODE/PDE/偏微分）、需数值积分器（RK4/BDF/DAE）求解、
golden 由独立数值 oracle 生成（非解析闭式）。

**Q-4 守卫 1 的含义**：L1 引入 §1.3 之外的物理（电化学、热传导、流体力学）→ **必须走 G2b**。
本 RFC 评估的是接入框架的可行性，不是任何具体 L1 物理模型的批准。

## 2. 候选路线评估

### 2.1 PyBaMM（FL-001 电池电化学）

| 维度 | 评估 |
|---|---|
| 许可证 | BSD-3-Clause（**待核实原文**——Q-4 守卫 2） |
| 接入方式 | Python 后端适配器（FL19 RFC 框架内）；PyBaMM 产出电压/电流/SOC 序列 → createFromParts |
| 依赖 | PyBaMM 本身（pip install）+ scipy/numpy——**违反零第三方依赖惯例**，须登记 CHG |
| 方程独立性 | PyBaMM 的 SPM/DFN 模型方程 ≠ FL-001 §1.3 解析式 → **G2b 级** |
| 教学价值 | 展示同一电池的 L0 行为级 vs L1 电化学级的差异 |
| 工期 | RFC 评审 M + PyBaMM 适配层 M + golden/oracle L = 总量 **XL** |

### 2.2 自写 ODE 后端（FL-001 热模型 / GT-001 非线性惯量）

| 维度 | 评估 |
|---|---|
| 许可证 | 自有代码（MIT），无第三方依赖 |
| 接入方式 | 同 B-5 RK4 框架——增加新状态变量（如温度 T），方程集扩展 |
| 方程独立性 | 新状态 = §1.3 之外物理 → **G2b 级** |
| 教学价值 | 展示热效应对电池性能的影响（L0 中不存在） |
| 工期 | G2b 规格评审 M + 实现 M + oracle/golden M = 总量 **XL** |

### 2.3 GT-001 非线性惯量（去掉 f≈f₀ 线性化）

| 维度 | 评估 |
|---|---|
| 方程 | 完整摇摆方程 2(H·S/f₀)·f·df/dt = ΔP（非线性，无解析解） |
| 接入方式 | 同 B-5 RK4 框架——替换 foStep 为完整非线性积分 |
| 方程独立性 | 方程集仍是 §1.3 的摇摆方程（只是去掉线性化近似）→ **不需 G2b**（方程范围不变） |
| 教学价值 | 展示线性化 vs 非线性在大幅偏频下的差异 |
| 工期 | **M**（不需 G2b，只是引擎内替换 + oracle/golden 重出） |

## 3. 排序建议

| 排序 | 路线 | 理由 |
|---|---|---|
| 1 | GT-001 非线性惯量 | 方程范围不变（不需 G2b），工期最短（M），教学增量明确 |
| 2 | 自写 ODE 热模型 | 自有代码、零依赖；但需 G2b（新物理） |
| 3 | PyBaMM | 许可证/依赖/工期均为最高成本；教学价值最高但风险也最高 |

## 4. Q-4 守卫核对

| 守卫 | 核对 |
|---|---|
| G-1 准入门绑定 | L1 需扩展方程集 → **必须走 G2b**（§2.1/§2.2 路线）；GT-001 非线性不需（§2.3 方程范围不变） |
| G-2 许可证 | PyBaMM BSD-3（待核实原文）；自写 ODE 无第三方 |
| G-3 验收路径 | L1 未经 G2b 不得出现在任何验收路径（含 SKIP 可选步） |

## 5. 结论

**GT-001 非线性惯量**（§2.3）是 v0.5.0 的最佳 L1 探路候选——不需 G2b、工期 M、教学增量明确。
**PyBaMM/热模型**（§2.1/§2.2）需 G2b 级评审，建议 V0.6.0+ 规划。
