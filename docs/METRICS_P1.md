## 2. 标签口径（与 pre/post 事件卡对齐）

### 2.1 事件锚点与相位语义（沿用既有裁定，不新立口径）

以 FL-001 现行事件（t_f = 20.0 s，dt = 0.1 s）为例；相位定义沿用 G0-DEC-05 与
DATA_CONTRACT_SPEC §2.5（`src/core/engine.js:1035-1038`、`src/core/checks.js:313-332` 实现）：

| 时刻/相位 | 语义 | 标签（真值） |
|---|---|---|
| `pre`（t_s = 20.0，`derivation='left_limit'`） | 事件时刻**左极限**（b=0、I_meas=25 A）；**不是** 19.9 s 采样行 | 正常（异常尚未生效） |
| `previous_sample`（19.9 s） | 上一**常规采样点**，与事件无特殊关系 | 正常 |
| `post`（20.0 s 采样行） | 右采样行（b=10 A、I_meas=35 A）；`timeseries` 的 20.0 s 行即 post | **异常起点**（注入已生效） |

推论（本草案的关键对齐点）：

- **真值异常区间为 [t_f, t_f + duration)**，起点按 t_f（20.0 s）计，**不按 19.9 计、不按
  pre 计**——pre 是左极限视图，不是异常区间的采样成员；
- **变化点（changepoint）= t_f**：与 SKAB 的 `changepoint` 列（0/1 逐点标注，SKAB README
  「Columns: anomaly / changepoint」）直接对齐——SKAB 的变化点也标在异常起点上；
- **检测评价窗只能在 t_f 右侧**：SKAB leaderboard 同款约束原文「the evaluated window of
  change points is to the right side of actual change point occurrence … impossible to capture
  event before it occurs」。对应到本仓：检测器在 t_f 之前报出异常一律计假报，不存在
  「提前检出」得分。

### 2.2 标签格式（SKAB 对齐）

SKAB 双标记并存（SKAB README：两套 markup 对应两个问题）：

1. **逐点标签 `anomaly ∈ {0,1}`**——异常区间内每个采样点标 1；
2. **变化点标签 `changepoint ∈ {0,1}`**——仅在区间起点标 1。

本仓对应：① 由 config 派生（family ≠ none 且 i ≥ i_f 的采样行为 1，i_f = t_f/dt）；
② 变化点行即事件卡 post 行（t_s = t_f）。两套标签与现有事件卡/事件窗口（`event-window` 检查，
checks.js:313）并存不合并：事件卡仍是教学展示口径，标签只是评价口径的机器化。

## 3. 指标定义（点级 / 区间级双口径）

双口径**同时报告、不互相替代**（SKAB leaderboard 同构：outlier detection 与 changepoint
detection 分列，各自报 F1 / FAR / MAR）。

### 3.1 点级口径（outlier detection 对应）

对每个采样点 i，预测标签 p_i 与真值标签 y_i 比较：

| 记号 | 定义 |
|---|---|
| TP | p_i = 1 且 y_i = 1 |
| FP | p_i = 1 且 y_i = 0 |
| FN | p_i = 0 且 y_i = 1 |
| TN | p_i = 0 且 y_i = 0 |
| 点级 precision | TP / (TP + FP) |
| 点级 recall | TP / (TP + FN) |
| 点级 F1 | 2·precision·recall / (precision + recall) |
| **误报率 FAR（点级）** | FP / (FP + TN)（SKAB leaderboard 列名 FAR, % 同口径） |
| 漏报率 MAR（点级） | FN / (FN + TP)（SKAB leaderboard 列名 MAR 同口径） |

注意：注入时长占全窗比例小（如 20 s / 60 s 窗内异常 40 s 时 TN ≫ TP），点级 FAR 对
「整段误开」不敏感——因此**区间级 FAR 必须并列报告**（§3.2），不得单报点级。

### 3.2 区间级口径（changepoint detection 对应）

- **真值区间** = [t_f, t_f + duration)（由 config 派生；多事件场景为区间集合）；
- **预测区间** = 预测标签连续为 1 的极大段；
- **区间检出判定**：预测区间与真值区间**重叠即检出**（宽松口径）；严格口径另定最小重叠比
  （P1 裁定时定值，草案不预设）；
- 区间级 precision = 真检出预测区间数 / 预测区间总数；区间级 recall = 真检出真值区间数 /
  真值区间总数；区间级 F1 同式；
- **误报率 FAR（区间级）** = 假事件数（与任何真值区间无重叠的预测区间数）/ 总预测区间数；
  另报「单位小时假事件数」（教学尺度 60 s 窗下比比例更直观）。

### 3.3 检测延迟（detection delay）

- 定义：`delay = t_detect − t_f`，其中 t_detect 为**首个**被判定为检出该事件的预测区间起点；
- **按采样点数 × dt 报告**（如 delay = (i_detect − i_f) × 0.1 s），避免浮点时刻歧义；
- **报告分布而非单值**：多 Run/多事件场景报告中位数与最大值（P0 教学单事件场景至少报告
  单值 + 其 dt 网格量化说明）；
- **下界说明**：受 dt 网格限制，delay ≥ 0 且为 dt 的整数倍；SKAB 的评价窗在变化点右侧
  （§2.1）保证 delay 不为负——负 delay（提前检出）在本口径中不可能合法出现。

### 3.4 定位口径（草案占位）

定位（fault localization，区分 sensor_drift 的作用位置）在 P1 若启用，建议以「定位正确率 =
定位正确的检出事件数 / 检出事件数」为占位定义；SKAB 无直接对应物（其标签不带作用位置），
该口径属本仓自定，须在 P1 裁定时单独评审。**本节不是 SKAB 借项**，列出仅为完整性。

## 4. 数值与时间尺度隔离（红线 4）

- SKAB 是水泵测试台实测数据（分钟级采样）；FaultLab 是 0.1 s / 60 s 教学尺度合成数据。
  **SKAB 的任何数值（阈值、特征、分数）不得迁移**；可迁移的只有 §2–§3 的**口径结构**
  （标签格式、指标定义、评价窗方向）；
- SKAB leaderboard 基线数值（其 README 表内 F1/FAR/MAR 百分比）**不得**在本仓引用作对照值
  ——「无对照不出百分比」：本仓若报百分比，对照物只能是本仓自己派生的真值标签
  （§2），不是 SKAB 分数；
- SKAB 实测数据可作「如果做实测对照需要什么标注与指标」的**参照**（清单 §5.2 原句），
  支撑 README 中 `not_performed` 类声明的严谨性，不构成任何本仓指标的实测背书。

## 5. 与内部一致性检查的关系（不得并列宣称）

  不构成模型验证或硬件验证」；
- 本文件指标（检出/延迟/误报）属于**另一层**证据：在真值标签已知的合成场景内的检测能力

  「检得出」；检测指标只说明「在标签已知的合成场景里检得出」，**不构成**模型验证、
  实测对照或任何对外能力宣称；
